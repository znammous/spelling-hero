# 🦸 أبطال الإملاء

لعبة لإتقان الإملاء بالعربية والإنجليزية: خطط تدريجية على شكل مناطق تُفتح واحدة بعد أخرى، ووضع حر يدخل فيه الطفل أو ولي الأمر كلماته بنفسه. تعمل بدون إنترنت، وكل البيانات محفوظة على الجهاز نفسه.

## التشغيل
- **على اللابتوب:** افتح `index.html` بضغطة مزدوجة (يُفضّل Chrome أو Edge).
- **على التابلت:** التثبيت كتطبيق يحتاج فتح اللعبة مرة واحدة من رابط `https`، ثم قائمة المتصفح ← «إضافة إلى الشاشة الرئيسية».

## كيف تعمل الخطة التدريجية
لكل كلمة سلّم من ثلاث درجات حسب مستوى الطفل فيها:
1. **رتّب الحروف**: تظهر الكلمة وتُنطق ثم تُخلط حروفها مع حروف مشتِّتة.
2. **أكمل الكلمة**: يُخفى الحرف موضوع الدرس (مثل ة أو الهمزة) ويختار الطفل من حروف متشابهة.
3. **اكتبها وحدك**: إملاء على لوحة مفاتيح داخل اللعبة. عند الخطأ يرى مكانه ثم يعيد كتابتها صحيحة.

الكلمة متقنة عندما يكتبها وحده بلا مساعدة، ومن يتقن 75% من منطقة يفتح التالية ويكتشف حيوانها.

## الألعاب الجماعية
من زر «العب مع إخوتك» في الرئيسية: **سباق الحروف**، و**شدّ الحبل**، و**مبارزة العقول**، ومعها سجل الفائزين والشهادة وصورة الفائز. ومن الرئيسية أيضاً **تحدّي العقل** الفردي بألعابه الثمانية.

- **جهاز واحد:** لاعبان، والأسئلة بالضغط فقط وبلا صوت.
- **عدة أجهزة:** حتى 4 لاعبين (لاعبان في شدّ الحبل)، وكل طفل يسمع ويكتب على جهازه. تحتاج الإنترنت وربط الأجهزة بحساب العائلة من لوحة ولي الأمر ← البيانات.

المزامنة تستخدم مشروع Firebase المشترك `tablehero-d582b`. ولكي تعمل أجهزة الأطفال المنضمة برمز يجب نشر `firestore.rules` من هذا المجلد:

```bash
firebase deploy --only firestore:rules --project tablehero-d582b
```

> هذا الملف يشمل قواعد المشروع كله. وأي نشر لاحق من مشروع آخر يجب أن يتضمن أسماء مستندات أبطال الإملاء، وإلا فقدت أجهزة الأطفال وصولها.

## هيكل الملفات
| الملف | الوظيفة |
|---|---|
| `js/data.js` | خطط الكلمات (`AR_REGIONS` و`EN_REGIONS`)، والعربية منها مشكولة للعرض والنطق، الرتب، المتجر، الشارات، الإعدادات الافتراضية |
| `js/engine.js` | مقارنة الإجابات، اختيار الكلمة حسب نقاط الضعف، الإتقان وفتح المناطق، رحلة اليوم |
| `js/speech.js` | نطق الجهاز والتسجيلات بصوت ولي الأمر |
| `js/store.js` | حفظ الملفات والقوائم على الجهاز ودمجها بين الأجهزة |
| `js/group.js` | الألعاب الجماعية والدعوات وربط الأجهزة |
| `js/brain.js` | ألعاب تحدّي العقل الثمانية |
| `js/sync.js` | المزامنة عبر Firebase |
| `js/winner.js` | صورة تهنئة الفائز |
| `js/world.js` و`css/world.css` | عالم حروفة: الأرنبة والمظهر الفاتح والأسماء البديلة. لكل بطل عالمه، ويغيّره من تعديل ملفه |
| `js/app.js` | الشاشات وطريقة اللعب |
| `sw.js` | حفظ ملفات اللعبة للعمل بدون إنترنت |

> عند تعديل أي ملف، غيّر رقم `CACHE` في `sw.js` حتى يصل التحديث للأجهزة.
